# JustAYoutubeDownloader
JustAYoutubeDownloader est un script en batch qui permet de simplement télécharger une vidéo YouTube (ou autre) en utilisant les projets yt-dlp et ffmpeg.

Utilisation :
- Téléchargez les 3 fichiers depuis le github et mettez les dans le même dossier.
- Téléchargez ffmpeg.exe et ffprobe.exe sur le github officiel ici : https://github.com/ffmpeg/ffmpeg et mettez les dans le même dossier.
- Téléchargez yt-dlp.exe sur le github officiel ici : https://github.com/yt-dlp/yt-dlp et mettez le dans le même dossier.
- Si votre vidéo est une vidéo YouTube classique, lancez youtube download.bat et suivez les instructions.
- ⚠️ Attention ! Si votre vidéo YouTube est une vidéo YouTube kids vous devrez lancer youtube downloader for kids.bat a la place.

 # English
JustAYoutubeDownloader is a batch script that lets you easily download a YouTube video (or other videos) using the yt-dlp and ffmpeg projects.

Usage:
- Download the 3 files from GitHub and place them in the same folder.
- Download ffmpeg.exe and ffprobe.exe from the official GitHub here: https://github.com/ffmpeg/ffmpeg and place them in the same folder.
- Download yt-dlp.exe from the official GitHub here: https://github.com/yt-dlp/yt-dlp and place it in the same folder.
- If your video is a standard YouTube video, run youtube download.bat and follow the instructions.
- ⚠️ Warning! If your YouTube video is a YouTube Kids video, you will need to run youtube downloader for kids.bat instead.
